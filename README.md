# Cloud Resume Frontend

Static resume site hosted on S3 + CloudFront.

## Live site
__https://macgillivary.dev__

## Architecture
- S3 static hosting
- CloudFront CDN
- HTTPS via ACM certificate
- Calls backend API for visitor counter

## Files
- `index.html` - Resume content
- `style.css` - Styling
- `script.js` - Visitor counter fetch
